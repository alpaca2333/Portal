# lgbm_ensemble_adaptive_v4 回测报告

## 1. 策略概述

### 策略思路

自适应集成选股 V4：在原版基础上新增行业动量加分、动态行业约束和增强版牛熊择时。融合两个 LightGBM 模型（Smart Money + Cross-Sectional），并通过多维度市场状态判断动态调整仓位水平。

### V4 核心改进

1. **行业动量加分 (P0)**：计算过去6个月各申万一级行业的流通市值加权收益率，强势行业(前10名)个股 ensemble_score +0.02，弱势行业(后10名)个股 -0.01
2. **动态行业约束 (P1)**：强势行业 max_per_industry=5，弱势行业 max_per_industry=2，其余行业 max_per_industry=3
3. **因子归因**：实现 get_factor_exposures() 接口，支持因子收益贡献分析
4. **增强版牛熊择时**：三级趋势确认(短MA5/20 + 中MA20/60 + 长60日新高低比) + 广度动量加速预警 + MA60/MA120中期趋势 → 连续仓位系数(0.10~1.00)，熊市同时缩减持仓数量和权重比例，预留现金仓位

### 继承自原版

- 双模型融合：Smart Money (0.5) + Cross-Sectional (0.5)
- 共识过滤（综合前5% 且至少一个模型前10%）
- 牛熊择时：三级趋势确认 + 广度动量 + 权重缩放
- softmax 加权 (temperature=5.0)，单股上限8%
- 个股止损 + 冷却 + 换手缓冲
