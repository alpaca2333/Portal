# 实施计划

- [ ] 1. 设置项目结构与门户集成
   - 创建黑洞子应用的目录结构（如 `/public/blackhole/`）及基础 HTML/JS/CSS 文件
   - _需求：4.2_

- [ ] 1.1 更新门户主页添加应用入口
   - 修改 `/public/index.html`，在应用网格（`.app-card`）中添加“3D 黑洞模拟”卡片并配置跳转路由
   - _需求：4.1、4.2_

- [ ] 2. 初始化 3D 渲染场景
   - 在子应用中引入 Three.js，初始化全屏 WebGL 渲染器、场景和摄像机
   - _需求：1.1_

- [ ] 2.1 配置摄像机交互与背景
   - 添加 OrbitControls 实现鼠标拖拽旋转和滚轮缩放功能
   - 加载并渲染高质量的星空/星云全景天空盒作为背景参照物
   - _需求：1.2、1.3_

- [ ] 3. 实现引力透镜效应着色器
   - 创建自定义的顶点着色器和片段着色器（Fragment Shader）材质用于渲染黑洞主体
   - _需求：2.1_

- [ ] 3.1 编写光线追踪与扭曲算法
   - 在片段着色器中实现 Raymarching 算法，根据引力透镜物理规律严重拉伸和扭曲背景光线
   - 确保视线穿过事件视界（史瓦西半径内）时渲染为纯黑色（无光逃逸）
   - _需求：2.1、2.2、2.3_

- [ ] 4. 渲染吸积盘与相对论效应
   - 在着色器中添加赤道平面发光吸积盘的渲染逻辑（基于纹理或体积渲染）
   - _需求：3.1_

- [ ] 4.1 实现光线弯曲视觉错觉
   - 编写数学逻辑，将吸积盘后方的光线弯曲渲染至黑洞上方和下方，形成经典黑洞视觉形象
   - _需求：3.2_

- [ ] 4.2 模拟相对论性多普勒效应
   - 在着色器中加入吸积盘旋转的 Doppler beaming 计算，使朝向观察者一侧变亮偏蓝，背离侧变暗偏红
   - _需求：3.3_
